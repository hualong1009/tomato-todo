# 🍅 番茄待办 v1.2.15 — 修好详情里的分组 / 紧急程度下拉

两个和「改所属分组 / 紧急程度」有关的问题一起修了：桌面端点开下拉后弹层跑到面板外面（看着像布局乱了），手机端点选项没有任何反应。

## 🐛 问题修复

- **桌面端下拉弹层跑位**：详情面板有 `backdrop-filter` 和开场动画残留的 `transform`，会让 `position: fixed` 的子元素以面板为参照系，弹层被顶到面板右侧外面。现在下拉弹层统一挂到 `body` 上，永远贴着触发按钮显示。
- **手机端选不了分组 / 紧急程度**：手机端适配层返回的状态快照是**同一个对象引用**（数据是原地修改的），React 认为状态没变就跳过重渲染，于是「选了但界面还是旧值」，看着像点了没反应。现在每次返回 / 广播都是新的对象与数组引用，选项点下去立刻生效（退出重进也能看到已保存，说明数据其实一直是对的）。

## ✨ 顺带优化

- 手机端返回键：下拉选项展开时先收起选项，而不是直接关掉整个详情面板。
- 弹层挂在 `body` 后不跟随列表滚动，所以外部一滚动就自动收起，不会飘在错位的地方。

## 🔧 实现细节

- `Dropdown` 用 `createPortal(menu, document.body)` 渲染弹层，并新增滚动收起逻辑。
- `capacitorApi.snapshot()` 改为 `{ ...state, groups: [...], todos: [...] }`，`emit()` 广播时也走快照，保证 React 一定拿得到新引用。

## 🧪 测试

- 单测 216 项通过，新增「状态快照每次都返回新引用」用例。
- e2e 新增断言：桌面端详情下拉弹层与触发按钮对齐且不超出面板、选择后立即生效；手机端选择分组 / 紧急程度立即生效。
