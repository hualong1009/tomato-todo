# 🍅 番茄待办 v1.2.12 — 手机端返回键按层级关闭界面

修复手机端按系统返回键（或返回手势）时应用直接退出的问题：打开「我的」「回顾」「分组」或待办详情后，返回键现在会先关闭这些界面，符合大家已经习惯的安卓返回逻辑。

## 🐛 问题修复

- **返回键逐层关闭**：设置（我的）、AI 回顾、视图与分组面板、新建待办面板、待办详情、更多操作面板和番茄钟全屏，打开的界面会按顺序逐个被返回键关闭，不再一按就退出应用。
- **嵌套界面顺序正确**：设置里再打开的确认弹窗会先关闭，再关闭设置本身，和桌面端按 Esc 的体验一致。
- **退到根界面才退出**：所有面板关完后，返回键会先收起搜索框、再从分组视图回到「全部」，最后才退出应用。

## ✨ 交互细节

- 待办详情处于编辑状态且有未保存修改时，返回键会先确认是否放弃修改，避免误触丢内容。
- 番茄钟全屏放大视图按返回键会收起为迷你计时器，不会中断正在进行的专注。
- AI 回顾生成过程中返回键不生效，避免请求结果被丢弃。
- 开启密码锁定后，返回键不会绕过锁定界面。
- 桌面端与浏览器预览的返回 / Esc 行为保持不变。
