# 🍅 番茄待办 v1.2.14 — 插入图片不再撞「5 万字符」上限

修复详情里插一张图就存不下待办的问题：图片是以 base64 内嵌进正文的，一张 100KB 的图编码后就有十几万字符，直接被「内容不能超过 50000 个字符」拦下。现在字数只统计**文字**，图片不再计入。

## 🐛 问题修复

- **插图片后无法保存 / 新建**：正文里内嵌图片（`![alt](data:image/…;base64,…)`）不再计入 5 万字上限，插几张图也能正常保存。
- **提示更明确**：超限时提示「待办内容不能超过 50000 个字符（图片不计入）」，避免误以为图片太大。
- **总量兜底**：单条正文（含图片 base64）总长超过约 8MB 时提示「图片太多或太大」，插入图片时就即时拦截，不会等到点保存才失败。

## ✨ 体验优化

- **接近上限才显示字数**：正文文字超过 4 万字时，编辑器工具栏右侧出现 `字数/50000` 计数，超出后变红，方便粘贴长文时心里有数。
- **AI 回顾不再被图片撑爆**：生成回顾时正文里的内嵌图片会被替换成 `[图片]` 占位符，不再把几十万字符的 base64 塞进提示词（省 token，回顾质量也更稳）。

## 🔧 实现细节

- 新增 `src/shared/content.ts`：`CONTENT_TEXT_LIMIT`（50000 字）、`CONTENT_MAX_CHARS`（约 8MB）、`contentTextLength()` / `describeInlineImages()`，统一处理 Markdown 图片、HTML `<img>` 与裸 data URL 三种内嵌形式。
- `addTodo` / `updateTodo` 的正文校验改用文字长度；正常文本的 5 万字上限与以前一致，旧数据不受影响。
- 新增 e2e 用例：手机端插入一张编码后远超 5 万字符的大图 → 不报错、保存成功、预览正常渲染。
