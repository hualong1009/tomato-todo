# 🍅 番茄待办 v1.2.9 — 修复安卓首次安装的状态栏主题

修复手机端全新安装后，状态栏没有跟随应用主题配色、必须进入设置再保存一次才能生效的问题。

## 🐛 问题修复

- **首次启动即应用主题**：此前设备没有保存过数据时，启动加载流程会跳过系统栏主题同步和 WebView 安全区初始化；现在无论是首次安装、已有设置还是本地数据损坏，均会在初始化后应用主题。
- **原生启动配色**：应用界面加载前，Android 状态栏先按系统深色/浅色模式设置；React 加载后再应用用户选中的星河暗色、晨光浅色或跟随系统主题，减少启动时的色差。
- 主题桥接若在启动早期暂时失败，后续应用同一主题时会重试。

已补充首次安装场景回归测试。若设备上已设置其他主题，启动时仍以已保存的应用设置为准。
