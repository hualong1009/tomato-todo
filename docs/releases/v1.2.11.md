# 🍅 番茄待办 v1.2.11 — 手机端隐藏桌面便签入口

手机端没有 Electron 桌面便签窗口，本版移除了会误导用户、点击后也不会出现桌面便签的 Pin 入口。

## 🐛 问题修复

- 手机端待办卡片不再显示 Pin/固定便签按钮；详情页不再显示「固定便签」和仅桌面端使用的便签颜色、透明度设置；「更多操作」也不再提供固定到桌面便签。
- **桌面端功能保持不变**：仍可从卡片、详情和操作菜单固定桌面便签并调整样式。
- 从桌面端备份恢复到手机的已有 `pinned` 状态不会被清除，跨设备数据保持兼容。

## ⚠️ Android 升级注意

v1.2.10 和本版使用相同的**正式签名**，可以直接覆盖升级。GitHub Releases 的 **v1.2.1～v1.2.9 APK** 曾误用每次不同的 debug 签名，无法直接覆盖 v1.2.11。若目前安装的是这些旧 GitHub APK，**先在旧版中把数据备份到 WebDAV 并确认上传成功，再卸载旧版、安装新版并恢复**；卸载会清除本机数据，没有可恢复备份时不要卸载。WebDAV 备份只包含待办与分组，账号、密码、AI 接口等本机设置需重新填写。
