# 🍅 番茄待办 v1.2.7 — 修复安卓 WebDAV 恢复报错

修复 v1.2.6 手机端从 WebDAV 恢复备份时可能出现 `Failed to execute 'atob' on 'Window': The string to be decoded contains characters outside of the Latin1 range` 的问题。

## 🐛 问题修复

- **手机端 WebDAV 恢复**：部分服务器以 JSON Content-Type 返回备份时，Android 的 HTTP 桥会把含中文的内容直接解析为文本；此前将该文本误当成 base64 解码，导致恢复失败。现在由原生 WebDAV 通道始终原样读取字节，再安全地传给应用解密/解析，与服务器的 Content-Type 无关。
- 加密 TTENC1/TTENC2 主备份、外置图片/附件与明文 JSON 均使用同一原始字节下载链路；异常响应不会覆盖手机本地待办。
- 补充含中文/emoji 的明文备份及异常响应回归测试。v1.2.6 引入的双向加密上传功能保持不变。

> WebDAV 是备份式同步：本机修改可自动上传；获取另一设备的变动仍需手动恢复。同时编辑不会自动合并，请在切换设备前确认上传完成。
