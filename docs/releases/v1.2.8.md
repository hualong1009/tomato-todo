# 🍅 番茄待办 v1.2.8 — GitHub Releases 更新提醒

新增桌面端与 Android 端的版本更新检测：应用启动后自动查看本项目 GitHub Releases，发现新版本时提示前往下载。

## ✨ 本版更新

- **启动自动检查更新**：仅当 GitHub 最新正式版高于当前安装版时弹出提示；离线或检查失败不会打断使用。
- **去更新 / 忽略此版本**：可打开本项目的 GitHub Releases 页面，选择适合自己设备的安装包；也可忽略这一版，忽略记录保存在本机，不影响后续新版本的提醒。
- **手动检查**：「设置 → 关于 → 检查更新」可随时重新检查，包括已忽略的版本。
- Android 端通过系统浏览器打开发布页。更新仅作提醒，**不会自动下载或安装**，也不需要 GitHub token。

## 📥 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Android | `tomato-todo-v1.2.8-release.apk` | 正式签名包，可覆盖 v1.2.0+ 正式版 |
| Windows | `tomato-todo-setup-1.2.8.exe` | NSIS 安装包，可覆盖升级 |
| Linux | `tomato-todo-1.2.8-x86_64.AppImage` / `tomato-todo-1.2.8-amd64.deb` / `tomato-todo-1.2.8-x86_64.rpm` | AppImage 免安装；deb 适用于 Debian/Ubuntu；rpm 适用于 Fedora/openSUSE |
| macOS | `tomato-todo-1.2.8-x64.dmg` / `tomato-todo-1.2.8-arm64.dmg` | 分别适用于 Intel / Apple Silicon；未签名，首次运行请右键打开 |

## 🔄 升级说明

Windows、Linux 与 macOS 可按各平台方式安装新版。Android v1.2.0+ 正式签名版可直接覆盖安装；早期 debug 版签名不同，卸载重装前请先备份数据。新版本中的忽略选项只针对当前发布版本，之后的版本仍会提示。
