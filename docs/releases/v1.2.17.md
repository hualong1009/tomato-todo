# 🍅 番茄待办 v1.2.17 — 修复 reasoning 模型连接测试误报

修复 Qwen 等 reasoning（推理）模型明明可用，却在「测试连接」时被错误提示「AI 接口没有返回文本内容」的问题。

## 🐛 问题修复

- **连接测试的输出预算过小**：此前测试请求固定只给 `max_tokens: 32`。Reasoning 模型会先生成内部思考内容，这 32 个 token 常常在最终回答 `连接成功` 之前就用完了。现在测试提高到 **512 tokens**，超时由 30 秒放宽到 60 秒，足以让推理模型完成思考并给出最终文本。
- **正确识别 reasoning 响应**：OpenAI 兼容网关常把思考过程放进 `message.reasoning_content`（部分网关使用 `message.reasoning`），最终回答仍在 `message.content`。应用继续只展示最终回答，不会把思维链写进 AI 回顾；但如果模型确实在最终输出前被截断，会明确提示「只返回了思考过程 / 输出长度已用尽」，并说明可提高输出长度或关闭思考模式，而不是笼统报「没有返回文本」。

## 🧪 测试

- 单测 **227 项**通过，新增 reasoning 模型有最终回答时正确解析、连接测试请求使用 512 tokens、思考阶段达到长度上限时给出可操作错误等覆盖。
- typecheck、全部 e2e、桌面与移动端构建均通过。
