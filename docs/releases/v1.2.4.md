# 🍅 番茄待办 v1.2.4 — Linux / macOS 发行包 · 便签修复

新增 Linux / macOS 发行包，修复固定便签小窗渲染问题。

## ✨ 本版更新

### 新增 Linux 与 macOS 发行包 🐧 🍎

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Linux | `tomato-todo-1.2.4-x86_64.AppImage` | 免安装，下载后 `chmod +x` 直接运行 |
| Linux | `tomato-todo-1.2.4-amd64.deb` | Debian / Ubuntu / Deepin 等 |
| Linux | `tomato-todo-1.2.4-x86_64.rpm` | Fedora / openSUSE 等 |
| macOS | `tomato-todo-1.2.4-x64.dmg` | Intel 芯片 |
| macOS | `tomato-todo-1.2.4-arm64.dmg` | Apple Silicon（M 系列芯片） |

### 🐛 问题修复

| 问题 | 说明 |
| --- | --- |
| 固定便签小窗显示整个应用（#7） | 打包模式路由传参丢失了开头的 `/`，小窗里渲染了完整主界面而非任务便签。双保险修复（主进程传参 + 路由兼容），并新增 e2e 回归测试 |

## 📥 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows | `tomato-todo-setup-1.2.4.exe` | NSIS 安装包，可覆盖升级 |
| Linux | AppImage / deb / rpm | 见上表 |
| macOS | dmg ×2 架构 | **未签名**：首次打开请右键 → 打开（或系统设置允许），Intel/M 系列选对应架构 |
| Android | `tomato-todo-v1.2.4-release.apk` | 正式签名，v1.2.0+ 可直接覆盖安装 |

## 🔄 升级说明

- 全平台可覆盖升级；安卓 v1.0/v1.1 debug 版用户需卸载重装（先备份）
- 便签窗口用户请升级后重新固定便签
