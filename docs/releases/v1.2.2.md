# 🍅 番茄待办 v1.2.2 — 跟随系统主题 · 安卓沉浸式体验修复

主题跟随系统 + 安卓沉浸式体验全面修复。

## ✨ 本版更新

### 界面主题

- **新增「跟随系统」主题模式**：设置 → 通用 → 界面主题新增第三张卡片「跟随系统」，自动跟随系统深浅色模式，系统切换的瞬间应用即时生效，无需重启
- 顶栏主题按钮改为三态循环切换：深色 🌙 → 浅色 ☀️ → 跟随系统 🖥️（悬停可查看当前状态）
- 桌面端与安卓端行为完全一致

### 安卓沉浸式体验

- **系统栏与界面背景完全无缝**：应用背景（含渐变、极光光晕）真正绘制到状态栏/手势条底下，告别"纯黑/纯白"色差
- **insets 智能注入**：屏幕旋转、弹出键盘、切换手势条模式时，内容实时重新留白
- **回顾 / 我的面板修复**：关闭按钮不再与状态栏重叠

### 🐛 问题修复

| 问题 | 说明 |
| --- | --- |
| 切换主题闪退 | 插件窗口操作必须切回主线程，否则抛 `CalledFromWrongThreadException` |
| 主题设置重启后丢失 | 闪退发生在防抖持久化之前，修复闪退后随之解决 |
| 状态栏/底部白色边框 | 关闭系统对透明系统栏的强制对比遮罩 |
| 列表从中部开始、底部图标悬浮 | 原生 insets 物理像素未换算为 CSS 逻辑像素，3 倍密度设备留白放大 3 倍 |
