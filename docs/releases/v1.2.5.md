# 🍅 番茄待办 v1.2.5 — 修复安卓键盘遮挡编辑面板

本版修复手机端打开新建待办等底部编辑面板、弹出输入法后表单被遮挡的问题。

## 🐛 问题修复

- **编辑面板不再被键盘遮挡**（[#11](https://github.com/hualong1009/tomato-todo/issues/11)）：系统手势条安全区与输入法高度分开处理，不再把键盘高度误当作底部留白。
- 面板根据可见视口和原生输入法高度调整位置；兼容 WebView 已随键盘缩小、仅可视视口缩小以及边到边布局未自动缩小的情况，避免重复避让。
- 面板高度受可见区域约束，内容可滚动，键盘弹出时标题、输入框和添加按钮仍可操作；收起键盘后恢复正常布局。

已补充键盘视口计算单测及移动端交互回归测试，并通过用户在真实手机上的验证。
