# 🍅 番茄待办 v1.2.3 — 新建待办支持图片与附件

新建待办支持图片与附件，勾选框对勾居中修复。

## ✨ 本版更新

### 新建待办

- **「补充详细内容」支持插入图片**：换成紧凑版富文本编辑器，可通过按钮选择、直接粘贴或拖拽插入图片，自动压缩到 1280px WebP 控制体积，与详情编辑面板能力一致
- **支持上传附件**：新建待办时即可上传附件（单个 ≤10MB），附件条目显示文件名与大小，可移除，随待办一起创建
- 快捷键：编辑器内 `Ctrl + Enter` 直接提交

### 🐛 问题修复

| 问题 | 说明 |
| --- | --- |
| 完成待办时对勾不居中 | 勾选框里的 ✓ 整体偏上约 0.6px——SVG 路径未计入圆头笔帽的延伸。像素级测量验证：修复前纵向中心 43.5/48，修复后 47.5/48，与横向一致，完美居中 |

- v1.2.0 及以上版本的安卓用户可直接覆盖安装
- 早期 debug 版（v1.0 / v1.1）用户因签名不同需卸载重装，请先通过 WebDAV 或本地备份导出数据
- 桌面版直接运行安装包覆盖升级
