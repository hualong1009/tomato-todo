# 🍅 番茄待办 v1.2.6 — 安卓与桌面端加密 WebDAV 双向备份

手机端现在不仅能恢复桌面端的加密备份，也能把自己的修改加密上传到同一个 WebDAV 位置，供桌面端恢复。

## ✨ 本版更新

- **手机端恢复加密备份**：支持桌面端当前 TTENC2（gzip + scrypt + AES-256-GCM）格式及旧版 TTENC1；远端图片、附件外置为加密 `blobs/` 时也能一并解密恢复。
- **手机端加密上传**：上传桌面端可直接读取的 TTENC2 主文件和加密图片/附件；附件按相同的 SHA-256 内容寻址算法拆分，先传资源、后写主备份文件。
- **自动上传**：开启 WebDAV 与「自动上传」后，手机端待办变动约 1.6 秒后上传；仍可手动点「立即备份」。
- **资源复用校验**：复用远端同名图片/附件前验证内容与当前加密密码；旧密码或明文资源会重新上传，避免主备份指向无法解密的附件。
- 错误密码、损坏的加密资源不会覆盖手机本地待办；手机端可设置加密密码和「图片与附件拆分上传」。

> **同步方式**：这是备份式同步，不会自动从远端拉取或合并并发修改。切换设备时，先确认当前设备完成上传，再到另一设备手动点击「从 WebDAV 恢复」；同时在两台设备编辑可能发生后上传覆盖先上传。

## 🔄 升级说明

Android v1.2.0+ 正式版及同签名的 v1.2.5 加密同步测试包可以直接覆盖安装。早期 debug 版签名不同，卸载重装前请先备份数据。若此前手机端用明文备份，请在 WebDAV 设置中填写与桌面端一致的加密密码后再上传，避免跨设备密码不一致。
