# 🍅 番茄待办 v1.2.13 — WebDAV 定时双向同步

在手机上改完待办，桌面端会自动拿到最新内容——WebDAV 从「只自动上传」升级为**双向同步**：定时检查远端有没有别的设备的改动，本机没改就自动拉取，本机改过就上传。

## ✨ 新功能

- **定时双向同步**：设置里新增「定时双向同步」间隔（默认每 5 分钟，可选 5 / 15 / 30 / 60 分钟或关闭）。每次同步只先读远端主备份的时间戳（不下载图片附件），确认需要同步才真正传输，流量消耗很小。
- **自动判断方向**：本机待办/分组有改动 → 上传；本机没改、远端被其他设备更新 → 自动拉取；两边一致 → 不发传输请求。
- **立即同步按钮**：WebDAV 页新增「立即同步」，一次点击即完成「判断 → 上传或拉取」；原来的「立即备份」保留为「仅上传」。
- **启动与回前台补同步**：桌面端启动 4 秒后、手机端切回前台（以及每 60 秒检查一次是否到间隔）都会自动同步一次，换设备后打开应用即可看到最新待办。
- **切后台前保存**：手机端切到后台时立刻把还在等待的自动上传发出去，避免改完就切走导致这次改动延迟很久才同步。

## 🐛 问题修复

- **手机端改状态不同步**：修复部分情况下手机端修改待办状态后没有上传到 WebDAV 的问题。现在除了变动后约 1.6 秒的自动上传，还有定时同步与切前台补同步兜底，即使上次上传被系统中断，下次同步也会按内容指纹发现漏传并补上。
- **冲突不再静默覆盖**：两端都有改动时保留本机数据并覆盖远端，同时弹出提示说明「已保留本机数据」，不再毫无提示地互相覆盖。

## 🔧 实现细节

- 用「本机内容指纹 + 远端 savedAt」判断谁更新（新增共享模块 `src/shared/webdavSync.ts`），指纹只算分组与待办，改设置不会触发无意义的上传。
- 老版本升级：首次同步没有指纹时按时间戳判断，新设备首次配置 WebDAV 会以远端为准，不会用空数据覆盖已有备份。
- 定时同步失败不弹提示打扰（错误记录在设置页的「上次错误」里），手动同步与手动上传失败仍会提示。

## 🔄 升级说明

- Android v1.2.10 起为固定正式签名，可直接覆盖安装，数据保留。若目前安装的是 v1.2.1～v1.2.9 的 GitHub APK（debug 签名），请先在旧版把数据备份到 WebDAV 并确认上传成功，再卸载旧版安装本版并恢复；卸载会清除本机数据。
- 已配置 WebDAV 的用户升级后默认开启定时双向同步（每 5 分钟）。如果不想让应用自动拉取，可在「设置 → WebDAV」把间隔改为「关闭定时同步」。
- 建议在每台设备上使用同一个加密密码；密码不同时同步会因解密失败而报错，本机数据不会被覆盖。
